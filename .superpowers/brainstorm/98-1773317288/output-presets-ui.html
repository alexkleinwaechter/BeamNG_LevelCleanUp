File Output, Presets & UI Design

How DecalRoads are written to BeamNG files, stored in presets, and configured in the UI.

1. File Output — Scene Writing

Output structure in level directory:

levels/{levelname}/
└── main/
    └── MissionGroup/
        ├── items.level.json  ← add SimGroup "DecalRoads" entry
        └── DecalRoads/
            └── items.level.json  ← all DecalRoad NDJSON lines here

Each DecalRoad line (NDJSON):
{"class":"DecalRoad","persistentId":"guid",
 "__parent":"DecalRoads",
 "material":"m_line_white",
 "textureLength":10.0,
 "breakAngle":3.0,
 "renderPriority":10,
 "startEndFade":[0,0],
 "distanceFade":[1000,1500],
 "drivability":-1.0,
 "improvedSpline":true,
 "position":[x,y,z],
 "nodes":[[x,y,z,width],...]}

Writer: DecalRoadSceneWriter
  → Follows BuildingSceneWriter pattern
  → Uses SimItemsJsonSerializer.Save() for NDJSON
  → Creates SimGroup first, then DecalRoad entries

2. Preset Integration

Added to existing TerrainPreset _appSettings:

"_appSettings": {
  "version": "3.0",  ← bump from 2.0
  ... existing settings ...
  "decalRoadSettings": {
    "enabled": true,
    "nodeSpacingMeters": 2.0,
    "junctionExclusionMarginMeters": 5.0,
    "materialLayerSets": {
      "Asphalt": { /* DecalRoadLayerSet JSON */ },
      "DirtRoad": { /* DecalRoadLayerSet JSON */ }
    },
    "osmLayerSets": {
      "motorway": { /* DecalRoadLayerSet JSON */ },
      "primary": { /* DecalRoadLayerSet JSON */ },
      "residential": { /* DecalRoadLayerSet JSON */ }
    }
  }
}

Backward compatible: presets without decalRoadSettings default to disabled. Version bump to 3.0 signals new capabilities.

3. AppData Default Layer Sets

Location:
%LocalAppData%\BeamNG_LevelCleanUp\
└── decalroad-defaults.json

Created on first run if missing. Contains:
{
  "version": "1.0",
  "osmLayerSets": {
    "motorway": { /* 4 lanes, edge lines, lane markings, edge blends */ },
    "trunk": { /* 4 lanes, similar to motorway */ },
    "primary": { /* 2 lanes, edge lines, center dashed, edge blends */ },
    "secondary": { /* 2 lanes, edge lines, center dashed */ },
    "tertiary": { /* 2 lanes, edge lines only */ },
    "residential": { /* 2 lanes, minimal markings */ },
    "service": { /* 1 lane, edge only */ },
    "track": { /* no markings, dirt edge blend only */ },
    "path": { /* disabled by default */ },
    "footway": { /* disabled by default */ }
  }
}

User edits this file to change global defaults. Project presets override these. If file is corrupted/deleted, app recreates from hardcoded fallback.
