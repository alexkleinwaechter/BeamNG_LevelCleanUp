Generation Pipeline & Junction Interruption

How DecalRoads are generated from splines and how junctions are handled in Phase 1.

Generation Pipeline (per spline)

For each ParameterizedRoadSpline in UnifiedRoadNetwork:

1. Resolve layer set
   → OsmRoadType override? → Material fallback? → AppData default?
   → If none found, skip this spline

2. Determine lane count
   → Parse OSM lanes=* tag from spline's OsmFeature tags
   → Fallback to LayerSet.DefaultLaneCount

3. Find junction zones for this spline
   → Query UnifiedRoadNetwork.Junctions for junctions involving this spline
   → Each junction → exclusion zone = junction position ± exclusion radius
   → Exclusion radius = max(contributing road widths) + margin

4. For each layer in the resolved LayerSet:

   4a. Expand layer
       → If IsMirrored: create two layers (left + right positions)
       → If IsPerLane: replicate for each lane boundary
       → Result: list of concrete positioned layers

   4b. Sample centerline nodes along spline
       → Use spline.SampleByDistance(interval) — reuse existing
       → Default interval: ~2m for smooth curves

   4c. Apply lateral offset per node
       → offsetPoint = center + normal × position × 0.5 × roadWidth
       → Get Z elevation from heightmap at offset point
       → Transform to BeamNG world coords

   4d. Apply junction interruption (if InterruptAtJunctions = true)
       → Mark nodes inside junction exclusion zones
       → Split node sequence into segments at zone boundaries
       → Each segment becomes a separate DecalRoad

   4e. Chunk segments (max 100 nodes per DecalRoad)
       → Share boundary nodes between chunks

   4f. Create DecalRoad objects
       → Set material, width, renderPriority, textureLength
       → Set position = first node's XYZ
       → Add to output list
