DecalRoad Layer Set — Data Model

The core definition that describes what DecalRoad layers to generate for a road. Review the structure and let me know if it covers your needs.

DecalRoadLayerDefinition (single layer)

DecalRoadLayerDefinition {
  // Identity
  Name: string              // "Center Line", "Left Edge", "Right Edge Blend"
  LayerType: enum           // CenterLine, LaneMarking, EdgeLine, EdgeBlend, TreadMarks, Custom
  IsEnabled: bool           // toggle on/off without deleting

  // BeamNG DecalRoad properties
  Material: string           // "m_line_white_discontinue", "m_road_asphalt_edge"
  Width: float               // meters (0.2m for line, 2.0m for edge blend)
  TextureLength: float       // texture repeat distance (default 10.0m)
  RenderPriority: int       // draw order (higher = on top, default 10)

  // Lateral positioning (like BeamNG road spline layers)
  Position: float           // -1.0 = left edge, 0.0 = center, +1.0 = right edge
  IsTrackWidth: bool        // if true, width scales with road width
  IsMirrored: bool          // auto-generate symmetric layer on opposite side

  // Lane-aware positioning (for lane markings)
  IsPerLane: bool           // if true, replicate between each lane

  // Fade/distance
  FadeIn: float              // fade at road start (meters)
  FadeOut: float             // fade at road end (meters)
  DistanceFade: float[2]    // [start, end] camera distance fade

  // Junction behavior
  InterruptAtJunctions: bool // cut this layer at junction zones (default: true for edges)
}

DecalRoadLayerSet (collection of layers for a road type)

DecalRoadLayerSet {
  Name: string              // "Highway Default", "Residential Road", "Dirt Track"
  IsEnabled: bool           // master toggle for entire set
  DefaultLaneCount: int     // fallback when OSM lanes tag missing (e.g., 2)
  DefaultLaneWidth: float   // standard lane width assumption (default 3.5m)
  Layers: List<DecalRoadLayerDefinition>
}

Override Resolution Cascade

For each ParameterizedRoadSpline:

  1. Check spline.OsmRoadType (e.g., "primary")
     → Look up in project preset's OsmLayerSets
     → If found: USE IT ✓

  2. Else: check spline.MaterialName (e.g., "Asphalt")
     → Look up in project preset's MaterialLayerSets
     → If found: USE IT ✓

  3. Else: check spline.OsmRoadType
     → Look up in AppData global defaults
     → If found: USE IT ✓

  4. Else: No DecalRoads generated for this spline
